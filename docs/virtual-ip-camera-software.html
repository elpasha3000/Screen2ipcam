What is a virtual IP camera?

Software that behaves exactly like a network camera, but the picture comes from a computer instead of a lens.

Found like a camera

ONVIF lets the NVR or VMS discover the PC with its normal search, read its streams and receive its motion events.

Streamed like a camera

RTSP carries an H.264 main stream for recording and a light sub stream for live view, at rtsp://PC-IP:554/screenlive and /screensub.

Recorded like a camera

Same timeline, retention, search, user rights and export as every other channel. No capture card, no HDMI encoder.

FAQ

What is a virtual IP camera?

Software that acts like a network camera, but the picture comes from a computer. Screen2ipcam publishes the Windows screen as an ONVIF Profile S camera with an RTSP H.264 stream.

Which VMS or NVR can record it?

Recorders and VMS that support ONVIF cameras, for example Hikvision, Dahua, Nx Witness and Blue Iris. Anything that opens an RTSP stream can use it too.

Do I need a capture card or HDMI encoder?

No. The screen is captured in software and sent over the network like any IP camera.

Does it need internet?

No. Video stays on your local network and the license is activated offline.
